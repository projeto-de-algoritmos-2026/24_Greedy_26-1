## Sobre 
Este projeto implementa um algoritmo guloso para resolver o problema de Alocação de Salas de Aula (Interval Partitioning). O objetivo é determinar o número mínimo de salas necessárias para alocar um conjunto de aulas com horários de início e fim definidos, garantindo que não haja conflitos de horário na mesma sala.

O programa recebe uma lista de aulas (intervalos) e utiliza uma abordagem gulosa para atribuir cada aula a uma sala de aula existente ou a uma nova, se necessário. O resultado é o número mínimo de salas e a alocação de aulas para cada uma delas. A implementação foi desenvolvida para praticar os conceitos de algoritmos gulosos ensinados na disciplina de Projeto de Algoritmos.

## Instalação 
**Linguagem**: JavaScript, HTML e CSS  
**Framework**: Não foi utilizado  
**Pré-requisitos**: Node.js (com npx) e navegador web atualizado

### Como rodar

1. Clonar o repositório

```bash
git clone https://github.com/projeto-de-algoritmos-2026/G24_Greedy_PA-26.1.git
cd G24_Greedy_PA-26.1
```

2. Iniciar o servidor local na raiz do projeto

```bash
npx serve .
```

3. Abrir no navegador

```txt
http://localhost:3000/
```

4. Encerrar o servidor quando terminar

```bash
Ctrl + C
```

> Alternativa caso prefira outro servidor local:
>
> ```bash
> npx http-server .
> ```
